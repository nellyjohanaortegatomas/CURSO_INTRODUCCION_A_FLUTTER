"Stateful widgets son widgets que pueden cambiar durante el tiempo de vida del widget y pueden actualizar la UI usando setState, estos no cambian durante la ejecucion y muestran informacion fija, los Stateful se usan cuando la informacion cambia de forma dinamica como checkbox o botones de radio, los Stateless se usan para textos o iconos que no cambian, setState notifica al framework que la interfaz debe redibujarse para mostrar la nueva informacion en la UI."
