"En Flutter, existe una funcion llamada popUntil que se usa para la navegacion entre pantallas dentro del stack, esta funcion permite regresar a una pantalla especifica eliminando todas las pantallas intermedias que estan encima, para usarla se escribe Navigator.popUntil y se define una condicion que indica la pantalla destino, normalmente usando las rutas definidas en main.dart, tambien puede utilizarse con condiciones del route stack, este metodo generalmente se coloca dentro de un boton o GestureDetector para ejecutarse al presionarlo, por ejemplo, si el usuario esta en screen 3 y se aplica popUntil hacia screen 1, entonces screen 3 y screen 2 se eliminan del stack y el usuario regresa directamente a screen 1, este metodo es util en procesos donde el usuario avanza por varias pantallas, como formularios, y necesita regresar directamente al inicio sin pasar una por una."
